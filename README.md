# NETWORK DNA · 고객관리

고객을 만나 미팅한 내용을 타임라인으로 쌓고, 다음에 다시 만날 때 지난 이야기를 바로 꺼내 보는 앱입니다.
설치 없이 브라우저에서 씁니다.

## 하는 일

- **명함 촬영 → 자동 크롭** — 카드 테두리를 찾아 배경을 지우고, 비스듬히 찍힌 것도 반듯하게 폅니다
- **기본 정보 자동 입력** — 회사·이름·직함·전화·이메일·주소를 읽어 채웁니다
- **고객카드 + 타임라인** — 미팅 / 요청사항 / 불만사항 / 특이사항 / 제공 샘플 / 할 일을 시간순으로
- **할 일 체크** — 완료하면 연한 글자로 바뀌고, 마감이 지나면 표시됩니다
- **검색과 그룹** — 이름·회사·연락처·이메일로 찾고, 그룹으로 나눠 관리합니다
- **구글 시트 실시간 연동** — 저장할 때마다 시트에 반영되고, 여러 기기가 서로 합쳐집니다
- **폰 주소록 저장** — 명함 사진까지 담은 연락처 파일로 넘깁니다

## 파일

| 파일 | 내용 |
|---|---|
| `network-dna.html` | 앱 본체. 이 파일 하나로 동작합니다 |
| `appsscript-고객관리.gs` | 구글 시트 연동 스크립트 |
| `구글시트-연동방법.md` | 시트 연결 방법 (10분) |

## 처음 설정

1. 앱을 열고 **설정** 탭으로 갑니다
2. **담당자 이름** 을 넣습니다
3. **명함 자동 인식** 에 Anthropic API 키를 넣습니다 (선택 — 없으면 직접 입력)
4. **구글 시트 연동** 은 `구글시트-연동방법.md` 를 따라 주소를 연결합니다

기록은 기기에 먼저 저장되고, 시트를 연결하면 자동으로 함께 보관됩니다.
API 키는 이 기기에만 저장되며 시트나 다른 곳으로 전송되지 않습니다.
